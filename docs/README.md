# Skills para PiggyBank Play

Copia `AGENTS.md`, `ARQUITECTURA.md` y `.agents/skills/` a la raíz de tu repositorio. Las skills son instrucciones para agentes de código; no instalan dependencias ni generan por sí solas la aplicación.

En OpenCode puedes pedir: «Lee AGENTS.md y aplica las skills react-native-architect, savings-engine y testing-security para implementar el motor de cuotas con pruebas». La carga automática de skills depende de la versión/configuración del agente.

Orden recomendado: arquitectura → motor de ahorro → persistencia → UI → gamificación → CI/release.
